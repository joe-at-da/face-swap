# Archived Scripts

This directory contains archived scripts that were used during development but have been superseded by newer versions.

## Parliament TV Stream Extraction Scripts

- `extract_parliament_stream.py`: Initial version using curl for HTTP requests
- `extract_parliament_stream_v2.py`: Updated version with improved error handling
- `extract_parliament_stream_v3.py`: Enhanced version with support for specific URL formats
- `extract_parliament_stream_v4.py`: Final curl-based version with comprehensive URL handling

These scripts have been replaced by `extract_direct_stream.py`, which uses yt-dlp for more reliable stream URL extraction.
